# 分章学习手册与发布简介

## 适用范围

用户要求学习文档、知识分享资料，或更新配套手册与简介时读取。只要求改简介时不重制视频；只要求删除章节时保持其他正文的实质内容。沿用已知受众、案例和确认规范，不重复索取已提供的信息。

## 内容组织

基于联合执行的知识底稿和教学蓝图，记录版本与知识到章/正文/讲稿的覆盖位置。知识审计、机制与共同事实由知识技能维护；发现知识缺口按[联合执行协议](../../chinese-tech-knowledge-decomposer/references/joint-workflow.md)回填，不另建相互竞争的事实源。学习正文仍须独立完整组织，不能直接复制底稿表格当教材。

首页交代完整任务、全局关系与阅读路径。每章对应一个完整问题：必要前提 → 具体机制 → 可追踪算例 → 边界或对照 → 累计结论 → 新情形检验。教学数字与真实测量区分；曝光、播放、点击等分母及观察窗口说明清楚。读者不看视频也应能理解正文。

完整系列目录、系统关系、累计笔记、较长复算和延伸练习可由手册承接；视频仍讲清本集核心答案、必要步骤和边界，不能把理解所必需的信息外移。只在用户要求或项目已有配套任务时制作手册，不为删视频目录而自动扩建资料。

完整口播可另存逐集附录，供备课查阅，不把未经重组的口播当作唯一正文。保留必要中间步骤；正文覆盖与原材料未展开方向如实区分，不靠字数声称覆盖全部领域。

## 推荐阅读结构

```text
手册/
  index.html                 首页、总览、章卡片
  第01章.html …              每章独立阅读
  讲稿目录.html              可选备课入口
  讲稿01.html …              按集独立的完整讲稿
  阅读样式.css
可编辑正文.md
离线分享包.zip
```

章节页包含当前章名与位置、章内小目录、前后章入口及返回首页；机制和公式可用独立演示框，表格有明确表头，章末结论有统一强调框。练习与答案分开，答案可折叠，不能在读题时直接露出。附录入口清晰但不打断正文。打印本章时去除导航和控件，保留表头与阅读层级；折叠答案若打印须展开或确保打印样式包含答案。

## 视觉与交互基准

继承视频的深蓝、青蓝与少量琥珀色语义；正文以白或浅暖色纸面为主，不强迫长文使用高饱和深色背景。中文字体沿用系列或可靠中文回退，标题、正文、辅助说明、公式采用统一层级。正文参考16–18px、行高1.8–2.0，控制行宽与段间距；不要为了容纳表格盲目缩小字号。表格在小屏可横向滚动，导航在小屏不遮挡正文。按钮和链接具备键盘焦点，文本可检索，不把文字整页转为图片。

不为装饰堆动画、机器人或无关素材；系统关系图和数据变化服务理解。离线包内使用相对路径、包含所需本地资源，不能依赖作者机器的F盘、字体文件绝对路径或外部CDN才能读取。

## 更新与验收

删除指定章节时同步处理所有交付版本，检查目录编号与链接。已存在的旧入口可指向新版首页，不能继续展示已删除内容。更新分享包并核对归档副本。

检查：算例复算、正文和附录完整性、链接与锚点、离线资源、折叠答案、前后章、桌面和小屏排版、表格与公式溢出、打印样式。结构检查不等于浏览器目视检查；无法预览时如实标记，不声称已看过画面。实际检查记录放工程中，不塞进读者正文。

## 简介模板

按题材改写，不机械套固定推荐系统内容：

```text
一个具体、有理由关心的问题。

这个系列面向[观众]，用[案例/算例/演示]解释[主线]。
本集通过[实际演示/对照]回答[具体问题]，并说明适用条件。

📖 配套学习手册：[阅读入口]
📦 离线分享包：[分享入口]

[必要且简短的教学设定说明]
[相关标签]
```

公开简介的链接必须适合观众访问；未提供或尚未发布时用“【待填：手册公开阅读链接】”“【待填：离线包分享链接】”，在交付说明中告知替换，不能编造网址。用户本机预览版本可使用真实绝对文件链接，但须明确是本地入口。用户要求同步简介时更新现有文案文件；是否上传、托管或公开发布由本次授权决定，写进skill不授予外部发布权限。
