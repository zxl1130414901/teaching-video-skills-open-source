# 知识与教学联合执行协议

协议版本1.3（2026-10-14）。两入口每轮各读一次，已读不重复、互不递归；此处只维护接口，知识规则归知识技能，教学/媒体规则归教学技能。

## 阶段、职责与停止位置

| 请求 | 知识侧 | 教学侧与交付 |
| --- | --- | --- |
| 拆知识 | 范围/机制/共同事实/缺口 | 核对可讲解性，交知识资料；不自动分集/写全套稿 |
| 课程/分集/多版本方案 | 底稿、依赖、事实 | 目标/完整任务/分集/演示/检验及深度试讲；文字方案，不制媒体 |
| 写讲稿/学习正文 | 核对本次事实变化 | 同版底稿组织所需正文/口播/分镜/手册，不自动配音 |
| 授权制作 | 复用底稿、补缺口、核对实际条件 | 指定完整单集/系列及图片/声音/字幕/视频/配套，真实验收 |
| 改字幕/版式/声音/简介 | 涉及术语/事实/结论 | 改指定范围、重检受影响项，不全量重编 |
| 创建/更新技能 | 职责/接口 | 技能及必要验证，不生产媒体 |

既有确认和制作授权按本轮请求继续，不新增审批，不扩展发布、联系观众或项目实现权限。局部任务仍联合使用，工作量限于涉及内容。

## 唯一底稿与最小交接

复用当前认可版本，旧资料只作来源；不能恢复已否定的集数或说法。交接引用路径、稳定ID及位置，至少让下游取得：

- 本轮对象/输出阶段/确认与否定要求；底稿及蓝图路径/版本、有关变更。
- 知识ID、完整问题、前提/依赖、解释位置；知识号/视频集号/版本号/模块号分别记录。
- 操作/中间结果/核心答案/边界/最小算例及验证状态；共同事实、术语日常说明、符号/单位、数据ID/条件/来源、现实流程/防护/简化、时间与视角。
- 与本次教学有关的可观察过程：可追踪对象/变量、改变条件或操作后的预期可见变化、结论依赖的连续时间/空间关系；已有连续素材或运行产物的位置/来源/核验状态，手设数值与实测的区别。缺连续素材时，给出可控机制演示的输入、变化规则、输出与边界；演示不能冒充实拍或真实系统验证。
- 模块输入输出/依赖、已有代码和产物、实际实现/运行范围；未核实、缺步、必须保留、可合并/另题接点及理由。

不复制全部正文。成套课程分别维护知识底稿和教学蓝图、相互引用；单文件也需独立区段ID/版本及维护职责。来源记录“已运行”、本轮只读报告、本轮实际复算/执行分别标明。

## 覆盖与回流

知识侧维护材料覆盖/命题对象机制/算例事实条件证据/依赖与变更；教学侧维护学习结果/任务/分集/各版解释与理解题、演示/代码讲解、观看结构/媒体/手册/发布交付。

教学覆盖记录`知识ID → 单元/版本 → 稿或正文位置 → 演示/镜头/代码接点 → 状态`。同一知识可服务多集、多知识可组成一集，拆合说明问题与依赖理由。A/B/C共享事实、机制及核心答案，各自完整讲解，分别增加直观过程、复算/假设、真实代码/运行；不能机械截一层底稿当口播。

知识底稿的组织顺序不等于成片呈现顺序。教学侧可先呈现现象、问题或结果，再组织必要前提与解释；重排后仍须接通依赖、明确条件与来源，不能用离散样例替代结论所需的连续证据。知识侧说明哪些关系必须保留，教学侧决定观看顺序、镜头与情绪安排。

发现缺口明确知识ID、对象/步骤/条件/证据及影响范围，知识侧改底稿，教学侧改相关稿/图/字幕/代码/手册/发布材料。不能为画面删推导、为复用音频保留错误、另建竞争事实或分集目录。局部只重验受影响项；“共享事实”不等于自动同步，实际改过并重核才标同步。

## 执行与完成

多步骤制作/续作/恢复及涉及媒体或证据复用的局部修订采用教学技能的[执行与复用规范](../../chinese-tech-explainer-video/references/quality-first-execution.md)：读取最小充分输入、复用稳定工程、输出摘要、按依赖和最终文件验证；不在两技能重复维护执行细则。

分别记录知识机制/证据、教学设计、观看结构、媒体实测；验收按当前阶段，规则以各自技能现行版本为准。历史证据可引用但不改称本轮实测，无真实观众测试不声称已学会。找不到配套技能先查安装位置；仍缺失保留已完成知识工作并说明缺段，不假称联合执行或擅自换流程。
