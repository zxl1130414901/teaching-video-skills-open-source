## 语音来源

历史语音合成使用 [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM)，有制作记录明确写到 VoxCPM2。语音模型是独立上游项目，技能包不分发模型、参考录音或私人配置。视频是否采用该模型、使用哪个版本及声音素材，需要对应制作记录确认；不要默认所有片段使用相同语音。详见[声音工作流](../skills/chinese-tech-explainer-video/references/voice.md)。

## 怎样维护未来版本

发布时为两份技能保存 Git commit 或 tag；每次制作在[对照表](视频版本对照.md)记录影片版本、两份技能的 commit、视觉规范版本、音频来源及可公开的播放链接。记录生成与后续复核分别使用的版本；没有快照或证据就写“待核实”。不要把私人路径、录音、密钥或未经授权的素材放进公开记录。
