# 观看检查与反馈

用于成片诊断、制作验收和有数据时的效果复盘。目标是定位具体问题与改法，不能用检查表证明观众一定喜欢。教学深度与技术指标仍按主技能分别验收。

## 设计与实际产物分开

先读当前范围、认可稿与实际交付路径。查看最终文件及有关时间轴，不能仅根据生成代码、分镜或验收模板判定成片。文字任务只做设计检查，不因未制作媒体阻断交稿。

| 检查 | 在实际产物中找什么 | 发现问题后的处理 |
| --- | --- | --- |
| 开场承诺 | 首帧、首句、声音是否立即指向标题疑问；第一次可见现象和实质认识出现在哪里 | 优先改实际开场、观众前提或包装对应，避免连续预告后才进入内容 |
| 过程可见 | 同一对象的动作、输入/变量、中间状态与结果能否被看见；变化/数字是否一致 | 补实际操作、连续素材或可控示意，不能只增加卡片与转场 |
| 信息推进 | 每段带来新认识、必要推理或思考机会；回顾是否有新用途 | 合并重复说明与仪式性导航，保留推导和有用途的停留 |
| 注意与节奏 | 当前只需观察什么；标题/路线/注释是否挤压主体；复杂过程能否跟上 | 主体放大、分步聚焦、合适的暂停/恢复；不按统一切镜频率处理 |
| 声画关系 | “这里/现在/变成”指向的对象、动作发生时刻、揭晓、语气与停顿是否相合 | 按最终录音重排触发/停留，保护实测过程的时间关系，局部补录 |
| 情绪与信任 | 问题是否值得关心，观众能否参与判断、得到解释；示意/实测是否清楚 | 用证据与自然作者判断增强可信度，不靠贬低、焦虑或伪造亲历 |
| 答案兑现 | 本集回答标题且说明关键边界，结尾有无多轮目录/笔记/预告重复 | 把答案落在具体判断上，收掉重复管理性内容 |

优先验证开场加一个完整机制单元，再检查后续计算/边界及整片。视觉样片、完整单元、最终成片是不同对象；粗版通过不能自动使后续改过的成片通过。

诊断建议用“实际时间/画面或原话 → 对观看的具体影响 → 改法 → 保留的知识 → 验证方式”。时间写清是旧片实测还是新稿计划；修改后重新生成章节与字幕时间。动效数量、像素变化比例和导航时长只是辅助线索，不设通用合格阈值。

## 检查证据的范围

- 抽帧可检查构图、文字和部分状态；不足以证明动作连续、节奏自然或声音情绪合适。
- 连续片段播放可检查其实际覆盖范围的运动和声画关系；看过片段不写“全片看完”。工具只能抽帧时如实记录未检查项。
- 音频响度、峰值、静音及ASR可查对应技术问题；声音自然度、重音和情境需实际听审，不由LRA等数值推断。
- 模型审稿/试答可发现知识缺口；真实观众的理解与观看意愿需真实反馈。不能虚构试看、访谈、留存提升或平台结论，也不自动联系观众。

## 有平台数据时再启用的反馈

先核对指标原名、计数与分母、样本量、时间窗口、流量来源及新老观众。游客播放占比不等于封面点击率；星级评价不换算为实际百分比；缺失值不当作零。

把时间对应起来：3秒跳出先看首帧、首句、音轨起点、包装承诺与受众匹配；几分钟后的目录冗余可能影响后段观看，不能直接解释最初3秒。结合可用的留存曲线定位，平均进度不能代替逐段留存。

小样本只形成待验证假设。比较作品需说明题材、长度、发布时间、来源/人群变化；平均观看时长与进度同时看，缩短时长会改变进度的分母。不把单集前后变化写成因果证明，也不设没有依据的“合格3秒跳出率”。

下一轮先选择有证据、可验证的主要改动，记录作品版本与包装、观察同类指标和样本条件，再决定是否扩展。样本不足时保留不确定性；不为试验擅自重复发布、删稿或操作账号。没有数据时先做设计/成片检查，不新增平台研究任务。

“观众抵触AI内容”可作为用户提出的背景假设，不直接当作本片跳出的已证实原因。若要引用当下平台政策、调查或流行趋势，查当前原始来源并注明时间、地区、人群和适用范围；不把某日观察写成永久规则。改进重点落在实际证据、作者判断、解释质量和可见过程上。
