# 中文科技教学视频

教学工作流版本 3.0（2026-10-14）。视觉规范提供字体、色彩与材质基准，按观察任务安排构图和运动。默认面向中国AI入门观众、中文普通话、横屏1080p/24fps；声音沿用当前项目选择，没有选择时用成熟沉稳且有故事感的男声。用户本次要求优先。**让观众通过可见过程得到答案，保留必要解释、计算与边界，不靠导航、重复总结或装饰运动撑时长。质量优先，不降低模型、推理设置或验收标准。**

## 联合入口与阶段路由

建议将两个技能同级安装并结合使用[知识拆解技能](../chinese-tech-knowledge-decomposer/SKILL.md)和[联合协议](../chinese-tech-knowledge-decomposer/references/joint-workflow.md)，本轮已读的不重复加载，不递归调用。配套技能不可用时自行按事实、假设、来源与边界建立底稿，不假装已调用。知识侧维护唯一事实底稿；本技能消费它，维护目标、分集、正文、口播、分镜、媒体及交付。已有底稿按版本与影响范围复用；发现缺步或矛盾回填知识侧。

## 教学与口播底线

- 引用底稿版本、知识ID和覆盖位置。先明确观众带着什么疑问而来、标题/封面承诺什么、能看到什么变化、最后能作出什么判断，再选完整任务与可检验学习结果。按问题和先修依赖分集，确定演示、边界与检验后估时；时长由有效解释决定，不能把知识点清单当蓝图。
- 用一句日常话说明要解决什么、学完能做什么。少量现实可成立的案例贯穿，先展开对象、操作、计算、中间结果和理由，再引入必要名称；说明现实流程、已有防护与教学简化。旁白主语/对象/动作清楚，按自然说话写，不用术语堆叠、长句或重复结论撑时长。
- 本课必要前提就地讲清；通用编程、系统数学等仅列所需基础与简短参考，不附带另一门课。历史/失败故事放在相关决策附近，解释收益、代价和条件。
- A直观、B推导、C实操共用事实与核心答案，各版讲解完整；分别增加可跟随过程、复算/假设、真实代码/运行，不按职业排除观众或把本版答案挪到另版。实操先运行授权阶段，再据产物写操作旁白；未授权实现时只规划接口与状态。
- 观众的好奇、参与和理解后的踏实感来自看见现象、获得判断依据和解释成立。互动可融入演示，不机械设考试、反转或评论任务；需要检验时给足依据、思考时间及同集答案。下一集承接剩余问题，不拖欠本集答案。新系列先验证一个完整教学单元；30–60秒样片仅可测外观/声音，不能代替教学验收。已有全量授权不重复暂停。

## 观看组织与导航

本节替代旧版“每集固定观看结构”。面向公开平台时，按第一次刷到本片的观众设计：就地交代必要前提，不要求先看系列目录。明确的课程导航需求按项目保留；不把任何结构扩展成所有视频的固定仪式。

1. **开场兑现：**从本题的可观察现象、操作、对比或结果进入，尽早交出一项有价值的认识。首帧、首句与封面标题对应；避免片头、问候、回顾、目录和“接下来会讲什么”连续挡在首次演示前。不硬套固定秒数，不先抛未铺垫术语。
2. **因果推进：**上一结果引出下一问题，尽量沿同一对象操作、比较和推导。需要定位才短暂显示路线/系统图；不在每章结束自动退回目录。
3. **按需导航与笔记：**完整系列目录优先放合集、简介或已有手册；复杂段落可用轻量定位。结论在有新用途时回忆，笔记可供暂停/查阅，不逐点累计朗读。教学目标与制作结构留在工程材料，转为观众有用的表达才进入口播。
4. **结尾兑现：**回答标题问题，给关键边界与实际判断，必要时简短承接下一问题。完整目录、逐条笔记、预告、互动不串成另一轮讲解。

文字与分镜标明观众此刻看到什么、得到什么、为何继续。使用导航时写清用途；不为填模板增加内容。初始估时包含操作、观察、推理和停顿；计划时间与成片实测分开。修改已有视频时同步检查口播、字幕、画面和章节时间。

## 连续演示与配音制作

- 核心机制落在实际变化上：同一对象的动作、变量改变、操作与结果、时间和因果对应。卡片依次出现、镜头缩放、背景运动只能辅助；静态停留可用于观察与推导。先按[分镜模板](references/storyboard-template.md)确认连续素材或可运行演示可得，缺失时先验证可控示意方案并标明来源，不把静图轮播算作已完成连续动作。
- 选择适合机制的实拍、屏幕录制、精确动画或它们的组合。AI 情景帮助建立场景，不能冒充真实实验。OpenMAIC、云舒 skills、Claude Motion 等只提供设计与实现参考；不强制依赖其安装、版式、测验流程或视觉风格。MP4 中呈现作者操作及结果，需观众亲手操作的内容另按授权交付。
- 真人配音路线：稿件与分镜同步设计 → 带临时声音和实际核心演示的可播放粗版 → 用户按自然语速分段录音 → 以最终录音调整画面停留/触发及字幕 → 成片验收。不能只交分镜表便称可试看，也不要求用户追赶临时配音。AI 配音仍是可选路线。详见[声音工作流](references/voice.md)；缺录音只暂停依赖它的最终混音。

## 媒体与交付底线

- 需要新人物/场景/插画/封面位图时，可使用当前环境可用的图像生成工具或有使用权的素材，并实际用于视频；没有需要不凑图。图像呈现场景与对象，精确机制、目录、数据与笔记用可控排版/矢量/代码，不能互相替代。人物连续一致，必要时参考原图编辑；中文文字由排版程序添加。保留原图、提示词、模式、路径、用途及来源/许可，AI情景标作示意，不能冒充真实测量或机构界面。工具不可用如实说明。
- 完整视频或封面交付时，每集独立**4:3、默认1200×900 PNG封面**，不能用16:9截图替代。沿用大字核心疑问、深蓝/白/青蓝及少量琥珀强调、纵深场景主体与清晰关系；继承参考原图的层级与质感，另做封面构图，不能直接套讲义卡片。缩小仍可读，不夸大证据；可复用本集位图重排。
- 显式变量字重、实际字形度量；溢出优先改写/换行/改容器/拆镜头，不任意缩字。用`scripts/check_layout.py`查真实渲染导出的布局，另查图像遮挡、连线、动态中间状态。构图给当前证据和动作足够空间，标题/路线不必常驻；复杂组件可扩展，不能为套旧版式删推导。外部语音服务按已有授权的项目/内容/用途执行。
- **一集一条完整主片**，不自行加上下篇、分章观看版或机械切片；章节可留在同片。纠正已有成片先找完整主片并核验；只有片段才处理重复开场/回顾与接续、核验同步再成完整文件。用户明确机械切片照范围执行。历史工程保留，索引/导航/发布文案只指当前交付。
- 配套手册有独立首页、分章页面、章内目录、上下章导航和独立讲稿附录，离线/小屏可读，源可用Markdown；正文展开机制、算例、边界、累计结论与练习答案，不只拼口播，也不把全书和全部讲稿堆成唯一长页。教材沿系列视觉、浅色阅读正文与深蓝导航。
- 已有手册则简介含阅读及离线分享入口；公开观众只用验证过的公开链接，本地路径仅用于本机，无公开链接留明确占位并说明待替换。不擅自上传、发布或联系观众。删除章节同时修正文/目录/导航/网页/源/分享包及编号；读者手册不单设“来源与使用边界”章节，必要事实就近引用，工程保留证据。

## 验收：教学、观看、技术分别记录

- **教学：**机制/输入输出完整、假设与边界成立、问题兑现、迁移题及理由充分；保留独立语义审查。无真实观众反馈只能称设计/模型审查。
- **观看：**按[观看检查与反馈](references/viewing-review.md)核对承诺、首次价值、过程可见性、信息推进、声音与画面指代、答案兑现。对照实际产物记录时间和证据；抽帧、连续播放、音频测量、听审及真实观众反馈分别记录，不能互相冒充。没有平台验证不宣称留存改善。
- **技术：**新生成/改变的最终产物检查实际字体边界/遮挡、字幕全文/术语/数值/同步、音色/峰值/响度、全片解码和音画时长、实际章节播放/跳转及交付链接。封面实测`宽×3==高×4`、无遮挡与缩小预览；交付算例对最终包隔离解压实际运行。局部变化按依赖重检，旧passed不证明新文件通过。

只交文字不以尚未制作的媒体阻断交付；记录本轮实际执行与引用历史证据的区别，不填不存在的实测。归档蓝图/稿/分镜/素材/规范/工程/成片/检查，保留版本，尊重用户已有目录。
