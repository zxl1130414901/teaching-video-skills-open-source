# 视频示例与技能版本

这里选取《AI 内容鉴伪》图像篇的三个制作阶段作参考。用户提供的 [B 站视频入口](https://www.bilibili.com/video/BV1Doxu6LEuk/)可供观看；目前尚未核实该页面与下列具体版本或分 P 的对应关系。

| 示例 | 视频版本 | 记录中的技能版本 | 参考价值 |
| --- | --- | --- | --- |
| E02《摄像头里的脸到了电脑里变成什么》 | v1 | 教学 2.5、知识 1.1 | 代表拆分知识技能后，以知识底稿和教学设计联合制作的阶段。版本信息来自教学与数据复核记录。 |
| E08《AI怎样换脸改过的画面怎样进入核验》 | 历史 v2 | 教学 2.6、知识 1.2 | 代表强化按阶段加载和复用证据的阶段。版本信息来自该历史版验收记录；不能直接套用到后来的 v3。 |
| E10《拍照片拍屏幕系统怎样发现》 | v2 粗版、v3 原工程 | 教学 3.0、知识 1.3、视觉 v4 | 代表以连续可见过程、自然开场和配音同步为重点的阶段。原工程记录了技能版本；后续自然开场版的修改需另行核对。 |

视频版本、技能工作流版本与视觉规范版本分别编号。这里的记录不是 Git commit 级别的完整快照绑定，也不代表技能升级后旧视频自动更新。各阶段参考来源和变化见[版本演进](版本演进.md)。

后续增加示例时，记录可公开的视频链接、视频版本、教学与知识技能的版本或 Git commit、视觉规范及制作或复核依据；未知信息标为待核实，避免提交本机路径或私人素材。
